电影选片墙effect: 'creative' 自定义变换 · 独立实例 #BzySw6

前六种 effect 都是 Swiper 写好的"成品"，creative 则把变换交给你自己定义：prev 控制上一张的位置，next 控制下一张的位置，每一侧都能单独设置 translate、scale、rotate、opacity。像电影选片墙一样——当前这张正对观众，左边一张缩小侧过去，右边一张放大压过来。

✍️ 任务 6 要求

初始化 Swiper('#BzySw6', { ... })：① 上一张缩小左移并带角度（prev：负向 translate + 更小的 scale + rotate）② 下一张放大右移进场（next：正向 translate + 比上一张更大的 scale，切换时放大到 1）③ 整体像电影选片墙（配合 shadowPerProgress 景深与透明度）。

⭐ 验证标准：拖动或点圆点时，左侧卡片缩小倾斜退到背后、右侧卡片更大且向右探出，切换时被放大推到正中

🎬 与演示四的 creative 按钮相比，这里把舞台收窄成 16:9、并让两侧卡片退到当前大图背后（translateZ 取负值），所以当前这张不会被遮住、两侧选片卡也能完整露出，不会被容器边缘裁掉。

双击放大看细节zoom 缩放模块 · 独立实例 #BzySw7

前六种都是"整张换"，这一种是"不换、只放大"：Swiper 自带的 zoom 模块能让图片原地缩放。结构上要多一层——把图片包进 .swiper-zoom-container，再打开 zoom 配置，双击图片就放大看细节，再双击还原。

✍️ 任务 7 要求

初始化 Swiper('#BzySw7', { ... })：① 开启 zoom（enabled: true）② 最大放大 3 倍（maxRatio: 3）③ 双击来回切换放大 / 还原（toggle: true）。

⭐ 验证标准：双击图片放大 3 倍、放大后可拖动查看细节，再双击恢复原样

🔍 关键在 .swiper-zoom-container：zoom 要靠它计算缩放基点，少了这一层双击没反应；toggle: true 才是"双击放大、再双击还原"，不写就只能放大不能收回。
